## 候选清单

做官网的时候，我对比了 6 套方案：

| 方案 | 优点 | 弃选原因 |
|---|---|---|
| WordPress | 成熟、模板多 | 模板感太重，走不出"博客"框架 |
| Notion 站 | 我熟、零学习成本 | 视觉定制能力有限，速度慢 |
| Webflow | 视觉强 | 月费 +$20，每次改要回 Webflow 后台 |
| 纯 HTML/CSS | 极致简单 | 加内容要手写一份新文件，不可持续 |
| Astro | 性能极致 | 学习曲线陡 |
| **Next.js** | **生态最大、Claude 最熟** | ← 选这个 |

## 选 Next.js 的真实理由

不是因为它"最好"。是因为：

1. **Claude 对 Next.js 的代码生成质量最高**——零代码小白靠 AI 写代码，**AI 最熟的就是最好的**
2. **生态最大**——任何想加的功能（MDX、登录、支付）都有现成方案
3. **Vercel 部署一键完成**——推 GitHub 自动上线，零运维

## 学到的

> 零代码小白选技术的原则就一句：**能不能让我专注写内容**。

任何让你花时间在"折腾系统"上的工具，都不是给你这种角色用的。

## 当前栈

- **框架**：Next.js 16 (App Router)
- **语言**：TypeScript
- **样式**：Tailwind CSS 4 + CSS 变量
- **内容**：MDX 文件 + JSON 文件（这篇文章就是个 .mdx 文件）
- **部署**：Vercel
- **包管理**：bun

加新文章 = 在 `content/journey/` 里新建一个 `.mdx` 文件 → push GitHub → 30 秒后线上。
