## 先给结论

今天，零代码小白用 12 小时上线了自己的网站：

- 🌐 URL：[https://soloos.cc](https://soloos.cc)
- 💰 成本：**¥70 一年**（域名）+ 一切其他 **¥0**

如果你 5 年前告诉我「12 小时能完成这件事」，我会笑你。

## 早上还在怀疑

今早起来，我看着昨天做的网站，心里冒出一句：

> "这看起来不够专业。SaaS 模板可能更厉害。"

我跟 Claude 说想再做一版 SaaS 风对比看看。

**它直接拒绝了我。**

给了 4 个反对理由 + 截图 Naval、Dan Koe、Paul Graham 的官网。最后那句话钉在我脑子里：

> *"Look professional 是 employees 玩的游戏，creators 玩的游戏是 look honest."*
>
> ——Naval

我犹豫了 5 分钟。**最后没重做**。

事后回看，**这是今天最重要的一个"不动作"**。

## 然后我就一头扎进去做事

整个下午到晚上，我跟 Claude 一起干完了三件事：

### 1️⃣ 搭 MDX 内容管道

简单说：**以后我加新文章 = 在 `content/journey/` 文件夹丢一个 `.mdx` 文件 → git push → 30 秒后线上更新**。

不需要后台。不需要 CMS。不需要登录系统。

文件就是后台。**这就是我现在写这篇文章的方式**——这是 `2026-05-04-day-02-soloos-cc-上线.mdx`，写完 push，你就能看到它。

### 2️⃣ 画 5 个手绘 SVG

不是用 Figma，**是 Claude 直接写的 SVG 代码**。

- 1 个 hero 大插画（一个人 + 笔电 + 漂浮的 ✻）
- 4 个 section 小图标（文件夹、书堆、笔记本、纸飞机）

全部用焦糖珊瑚色 + 黑线手绘风。亮模式黑线，暗模式自动变象牙色。

**SVG 不需要"画图工具"**，它就是代码。这个认知改变了我对"做设计"的理解。

### 3️⃣ 推到 GitHub + 部署 Vercel + 绑定域名

我以为要花 3 小时配置服务器。**结果 30 分钟搞定。**

- GitHub 仓库 `soloos-home`：开源，公开（[源码在这](https://github.com/giioob/soloos-home)）
- Vercel 自动监听 → 我每次 push，30 秒后线上更新
- Cloudflare 买域名 + 配置 DNS：5 分钟
- HTTPS / SSL 证书：Let's Encrypt 自动免费
- 全球 CDN：100+ 个数据中心，访客在哪都快

**整个 stack 0 元/月**。Vercel Hobby 永久免费 + Cloudflare 域名按成本价。

## 看到 URL 在手机上加载那一刻

我用手机打开 [https://soloos.cc](https://soloos.cc)。

**亮模式 → 切暗模式 → ✻ 在转 → 翻到底 → 看到 5 个二维码 → 看到自己的照片**。

发了张截图给一个朋友。他第一句："这是你做的？"

那一刻我有个清晰的感受：**之前两年我攒的所有焦虑，本质都是因为没有作品**。

光是"做了一个东西能给人看"，比 100 篇方法论文章都顶用。

## 今天没想到的 4 件事

### 1️⃣ 代码不是技术问题，是定位问题

真正卡住我的从来不是 "怎么写 React"，是 **"我到底要做什么"**。

Claude 给我代码很快。但前提是我能说清楚我要什么。

**结论**：零代码小白要练的不是技术，是**说清楚自己想做什么**的能力。

### 2️⃣ 零代码不等于用模板

我以为零代码意味着用 WordPress 模板拼一拼。

其实不是。**零代码意味着我不写代码——但代码还是被写出来了，只是被 AI 写**。

我的工作不是工人。**是产品经理 + 设计师**。这是两种完全不同的角色。

### 3️⃣ 部署比 5 年前简单 10 倍

5 年前买服务器 + 装 Linux + 配 Nginx + 申请 SSL，没几天搞不定。

现在：

```
git push → 30 秒后全球 CDN 上线
```

**新人比老人有优势的地方**：没有"以前很难"的包袱，敢直接走最现代的路径。

### 4️⃣ 上线那一刻没有兴奋，只有平静

我以为做完会很爽。

**没有"哇好爽"的多巴胺。**

只有一个安静的"哦，原来真的可以"，然后想着下一步该写哪篇文章。

**这种平静比兴奋更有续航力。** 兴奋会消退，平静不会。
