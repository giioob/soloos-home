## 然后我就一头扎进去做事

整个下午到晚上，我跟 Claude 一起干完了三件大事：

### 一、搭 MDX 内容管道

简单说：**我以后加新文章 = 在 `content/journey/` 文件夹里丢一个 `.mdx` 文件 → git push → 30 秒后线上更新。**

不需要后台。不需要 CMS。不需要登录系统。

**文件就是后台。**

这篇你正在读的文章——就是这么发出来的。

### 二、画 5 个手绘 SVG

不是用 Figma。**是 Claude 直接写的 SVG 代码**。

我之前以为画 SVG 必须得有"画图工具"。**今天才明白：SVG 就是一段代码**。

亮模式自动黑线，暗模式自动变象牙色。**一套 SVG 顶两套设计**。

### 三、推到 GitHub + Vercel + 绑定 soloos.cc 域名

我以为要花 3 小时配置服务器。**结果 30 分钟。**

- GitHub 仓库：开源，公开
- Vercel 自动监听：每次 push 30 秒后线上更新
- Cloudflare 域名：¥70/年，5 分钟配置 DNS
- HTTPS、CDN、SSL 证书：全部自动，免费

**整个 stack 月费 0 元。**

## 我没想到的 4 件事

### 1. 代码不是技术问题，是定位问题

真正卡住我的从来不是 "怎么写 React"，是 **"我到底要做什么"**。

Claude 给我代码很快——但**前提是我能说清楚我要什么**。

**零代码小白要练的不是技术，是说清楚自己想做什么的能力**。

### 2. 零代码 ≠ 用模板

我以为零代码意味着用 WordPress 模板拼一拼。

其实不是。**零代码意味着我不写代码，但代码还是被写出来了，只是被 AI 写。**

我的角色不是工人。是**产品经理 + 设计师**。

这是两种完全不同的角色。

### 3. 部署比 5 年前简单 10 倍

五年前买服务器 + 装 Linux + 配 Nginx + 申请 SSL，没几天搞不定。

现在就一句话：**git push → 30 秒后全球 CDN 上线**。

新人比老人有优势的地方：**没有"以前很难"的包袱**，敢直接走最现代的路径。

### 4. 上线那一刻没有兴奋，只有平静

我以为做完会很爽。

**没有"哇好爽"的多巴胺。**

只有一个安静的"哦，原来真的可以"，然后想着下一步该写哪篇文章。

**这种平静比兴奋更有续航力**。兴奋会消退，平静不会。

## 公众号排版小贴士（你看到这里我才说）

**这篇文章直接复制到公众号编辑器，会丑得没法看**。

推荐流程：
1. 复制本文 markdown（公众号文章源文件你网站任意一篇文章右键查看源码也能拿）
2. 粘贴到 [mdnice.com](https://mdnice.com)（墨滴·Markdown 公众号排版工具，免费）
3. 选个主题（推荐"奶白"或"简洁"）
4. 复制排版后的 HTML
5. 粘贴到公众号编辑器
6. 加封面图（用 SoloOS logo 或网站截图）
7. 发表

**全程 5 分钟。**
